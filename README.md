# Homebrew Tap for Genomix CLI

AI-powered CLI for DNA sequence and genome analysis.

## Installation

```bash
brew tap hermias1/genomix
brew install genomix-cli
```

## Usage

```bash
genomix setup    # Check dependencies
genomix init     # Initialize a project
genomix          # Start interactive mode
```

For more info: https://github.com/hermias1/genomix-cli
